## 5. 出问题怎么回滚（1 条命令）

```bash
cd /root
tar -xzf dsp-backup-<第 1 步生成的时间戳>.tar.gz     # 代码+数据一起还原
systemctl restart douyin-spark
```

> 数据与代码在同一份压缩包里，所以「更新出错」和「数据被改坏」都能一次还原。

## 6. 更新后建议：每天自动备份（3 行搞定，强烈建议）

```bash
mkdir -p /root/auto-backup
( crontab -l 2>/dev/null; echo "30 3 * * * cd /root/douyin-spark && tar -czf /root/auto-backup/dsp-\$(date +\%F).tar.gz data && find /root/auto-backup -name 'dsp-*.tar.gz' -mtime +7 -delete" ) | crontab -
crontab -l
```

效果：每天 03:30 自动打包 `data/`，**只保留最近 7 份**（约 7×几十 MB）。
恢复方式：`cd /root/douyin-spark && tar -xzf /root/auto-backup/dsp-2026-10-01.tar.gz && systemctl restart douyin-spark`

## 7. 备案通过之后（另做，见《域名与HTTPS部署.md》）

1. 阿里云 DNS 加 A 记录：`spark` → `47.115.221.82`
2. 阿里云证书服务：为 `spark.twilightsnowzhong.me` 申请免费证书（DNS 验证）→ 下载 Nginx 版
3. 服务器新增 nginx 站点（**注意用 1.18 兼容写法**）：

```nginx
server {
    listen 443 ssl http2;
    server_name spark.twilightsnowzhong.me;
    ssl_certificate     /etc/nginx/ssl/spark.pem;
    ssl_certificate_key /etc/nginx/ssl/spark.key;
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

4. 阿里云安全组放行 **TCP 443** → `nginx -t && systemctl reload nginx`
5. 国内验证 `curl -I https://spark.twilightsnowzhong.me` → 通过后**关闭 8000 与 8443**
6. 手机主屏幕图标换成新域名（并重新粘贴一次令牌）

> 备案没通过之前，**不要**开 443：未备案域名的 443 在国内会被拦（和 8443 的 SNI 拦截同一回事）。
