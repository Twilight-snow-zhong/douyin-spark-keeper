📖 使用说明

            
没看过 README 也没关系，这里 3 分钟带你上手：添加账号 → 关联抖音 → 加好友 → 设定时，之后每天自动帮你续火花。

          


          
🚀 快速上手（3 步）

          

            

              1添加账号
              
「账号管理」→「+ 添加账号」，给账号起个名字（如大号 / 小号），支持多账号同时管理。

            

            

              2关联抖音
              
「概览」→「📱 网页内扫码登录」，用手机抖音 App 右上角扫一扫确认登录。也可以用 extract_cookie.py 导出登录态后上传。

            

            

              3加好友 + 设定时
              
「好友与消息」：获取聊天列表 → 勾选好友加入名单 → 填好消息模板 → 保存。「定时与浏览器」：设好每天发送时间，开启「参与每日定时发送」。火花天数会自动更新，也可点「🔄 同步火花」手动刷新。

🖥 服务器部署与管理

          



              
🚀 一键部署

              
    
                
  • 把整个项目文件夹上传到 Debian / Ubuntu 服务器
    • 
                
  • 执行 sudo bash deploy/deploy.sh，自动完成：装 Python 依赖、Playwright、Chromium、swap、时区、访问令牌、systemd 服务
    • 
                
  • 完成后访问 http://服务器IP:8000，令牌保存在 .env 文件
    • 
              

              📖 部署教程 · 点击打开（从注册开始）
            

            

              
🛠 systemd 管理

              
    
                
  • 开机自启 + 崩溃 5 秒自动重启（脚本已配好）
    • 
                
  • 常用命令：
    • 
              

              
systemctl status douyin-spark     # 看状态
systemctl restart douyin-spark    # 重启
journalctl -u douyin-spark -f     # 实时日志

              
    
                
  • 改 .env（端口 / 令牌）后重启生效

工具已自动停止本轮，稍后会自动补发。建议把时间抖动调大一点、每次发送人数调低，别发太频繁；若频繁限流请暂停使用一段时间。

依次检查：账号是否「启用」、好友名单里是否有「启用」状态的好友、登录态是否有效（概览会话状态）、时间是否设对。还不行就看「日志」页排查。

「获取聊天列表」用于重新抓取列表、勾选加好友；「🔄 同步火花」用于更新已有好友名单的火花天数与头像。其实每次手动 / 定时发送后，程序也会自动顺手刷新一次天数。

锁屏：程序照常运行，定时发送不受影响。休眠 / 睡眠：系统暂停，程序不会运行，当天错过的那次不会自动补发。
想要 24 小时稳定：在 Windows「电源和电池 → 屏幕和睡眠」里把睡眠改为「从不」（插电时也设一遍），只让屏幕关闭即可。

            
            
              
开机自启动登记的是当时的绝对路径。文件夹移动或改名后，去「⏰ 定时与浏览器」把「开机自启动」开关关闭再打开一次即可重新绑定新路径；之后重启电脑验证一次。另外文件夹改名后建议顺手重启一次程序（start.bat），让数据目录也切到新路径。

面向从没碰过服务器的新手，从注册账号到网页打开全程手把手。以阿里云轻量应用服务器为例（腾讯云轻量流程几乎一样，差异有备注）。全程约 30~60 分钟，大部分时间是等服务器装环境。完整版文档见项目里《部署教程-阿里云从零开始.md》。


        
准备工作

        
需要：手机（收验证码/实名认证/收通知）、身份证、支付宝或微信、一台 Windows 电脑。花费：轻量服务器新用户活动价通常几十到一百多元一年（以购买页为准），之后运行基本不花钱。


        
第 1 步 · 注册阿里云并实名

        
打开 www.aliyun.com → 右上角「免费注册」→ 手机号 + 验证码 → 按提示完成实名认证（身份证 + 支付宝扫脸，几分钟通过）。不实名买不了服务器。


        
第 2 步 · 购买轻量应用服务器

        
搜索「轻量应用服务器」→ 立即购买，按下面选：

        ① 地域：选离你近的（广州 / 上海 / 深圳等）

        ② 镜像：系统镜像 → Ubuntu 22.04（重要：别选 Windows，程序是 Linux 的）

        ③ 套餐：2 核 2G 起步够用；时长 1 年（活动价最划算）

        确认订单 → 支付。腾讯云轻量在 cloud.tencent.com/product/lighthouse，流程一样。


        
第 3 步 · 拿到 IP 和密码

        
进入控制台 → 轻量应用服务器 → 等实例「运行中」，记下公网 IP；在实例详情点「重置密码」自己设一个（务必记住），按提示重启实例。


        
第 4 步 · 开放防火墙 8000 端口（关键！）

        
新服务器默认只开 SSH(22)。到实例「防火墙」页签 →「添加规则」：协议 TCP、端口 8000、来源 0.0.0.0/0 → 保存。不开放 8000，网页永远打不开。


        
第 5 步 · 连接服务器（Windows）

        
方式 A（最简单，无需装软件）：按 Win + R 输入 powershell 回车，然后：

        
ssh root@你的公网IP

        
首次连接输入 yes → 输密码（输入时屏幕不显示任何字符，正常）。看到 root@xxx:~# 即连上。
方式 B：下载 FinalShell / Xshell 图形化连接（主机填 IP、用户名 root、密码）。
连不上？查密码 / 是否重启实例 / 22 端口防火墙。


        
第 6 步 · 上传程序到服务器

        
下载 WinSCP（winscp.net，选简体中文）→ 登录（主机=IP，用户名=root，密码）→ 右侧进 /root → 把整个「服务器版」文件夹拖到右侧。建议先删掉本地的 .env（服务器会自动生成新令牌，更安全）。


        
第 7 步 · 一键部署（耐心等）

        
回到 SSH 终端：

        
cd /root/服务器版
sudo bash deploy/deploy.sh

        
脚本自动完成：装 Python 依赖 → 下载 Chromium（几百 MB，最慢 5~15 分钟，耐心等） → 1G 内存自动建 2G swap → 设时区 → 生成访问令牌 → 注册 systemd 服务。
看到「部署完成！」和「访问令牌: xxx」就是成功，把令牌记下来（之后可 cat /root/服务器版/.env 查看）。


        
第 8 步 · 打开网页开始用

        
自己电脑浏览器打开 http://你的IP:8000 → 输访问令牌 →「账号管理」添加账号 →「概览」→「📱 网页内扫码登录」→ 选引擎 →「开始扫码登录」（用网页内二维码模式，服务器无桌面弹不了窗）→ 手机抖音扫码确认 → 配好友名单和消息模板 → 定时与浏览器设好时间并开启「参与每日定时发送」→ 先「干跑测试」再「立即发送」。


        
第 9 步 · 配手机通知（强烈建议）

        
服务器没有桌面，通知弹不出来。「🔔 通知」→ 开启「📱 webhook 推送」→ 服务选 ntfy → 地址填 https://ntfy.sh/随便起个话题名 → 手机装 ntfy App 订阅同话题 → 点「🧪 发送测试通知」验证。


        
第 10 步 ·（可选）HTTPS 加密

        
nginx 反代 + certbot 免费证书，配置示例见 DEPLOY_SERVER.md 第五章。公网部署建议尽快配上。


        
🗓 日常管理速查

        
systemctl status douyin-spark     # 看状态
systemctl restart douyin-spark    # 重启
journalctl -u douyin-spark -f     # 实时日志（Ctrl+C 退出）

🚨 常见卡壳点

        
· 网页打不开 → 防火墙 8000 端口没加 / systemctl status 不是 active

        · SSH 连不上 → 密码错 / 没重启实例 / 22 端口被挡

        · 部署报错 → 多为网络问题，重跑 deploy.sh（可重复执行）

        · 扫码失败 → 确认用「网页内二维码」模式，journalctl -f 看日志

        · 公网怕被扫 → 尽快配 HTTPS，令牌勿外泄，不用时可关掉 8000 防火墙规则

程序会在发送完成、登录态过期、疑似限流时提醒你。两种方式可同时开启：Windows 桌面气泡（个人电脑）和 webhook 推送到手机（服务器 / 出门在外）。


        
方式一 · Windows 桌面通知（个人电脑）

        
① 先确认系统开关：设置 → 系统 → 通知 → 打开「获取来自应用和其他发送者的通知」；「专注助手（勿扰）」要关闭

        ② 网页侧边栏点「🔔 通知」→ 保持「桌面通知」开启 → 点「保存」

        ③ 点「🧪 发送测试通知」，右下角弹出系统气泡即成功。


        
方式二 · webhook 推送到手机（服务器 / 出门在外）

        
三种免费服务任选其一，流程都是：网页「🔔 通知」→ 开启「📱 webhook 推送」→ 选服务 → 填地址/Key → 保存 → 测试。下面分别讲。


        
① ntfy（最简单，免注册）

        
1. 手机安装「ntfy」App（或手机浏览器打开 ntfy.sh）

        2. 自己定一个话题名，越独特越好（如 douyin-spark-abc123），避免别人碰巧看到你的消息

        3. 网页通知设置：服务选 ntfy，地址填 https://ntfy.sh/你的话题名

        4. 手机 App 点「+」订阅同一个话题名（大小写要完全一致）

        5. 点「🧪 发送测试通知」，手机收到即成功


        
② Server酱（推送到微信）

        
1. 浏览器打开 sct.ftqq.com，用 GitHub 账号登录

        2. 页面上点「SendKey」→ 复制（形如 sctp1234...）

        3. 网页通知设置：服务选 Server酱，「地址 / Key」填 SendKey

        4. 保存 → 点「🧪 发送测试通知」，微信服务号收到即成功

        说明：Server酱的推送走微信「服务号」，需要你的微信能收到服务号消息。


        
③ PushPlus（推送到微信）

        
1. 浏览器打开 pushplus.plus，用微信扫码登录

        2. 登录后首页复制你的 token

        3. 微信里搜「PushPlus 推送加」并关注（不关注就收不到！）
4. 网页通知设置：服务选 PushPlus，「地址 / Key」填 token

        4. 保存 → 点「🧪 发送测试通知」，微信「PushPlus」服务号收到即成功


        
🧪 测试与验证

        
每次改完配置，务必点「🧪 发送测试通知」。弹窗里会逐渠道显示结果：✓ 表示成功，✗（原因） 表示失败及原因。保存后不测试、直接等提醒，容易白等。


        
🚨 收不到提醒怎么办

        
· 桌面气泡：查系统通知总开关、专注助手是否开着

        · ntfy：话题名前后是否完全一致（含大小写）、App 是否已订阅、服务器能否访问外网

        · Server酱 / PushPlus：SendKey / token 是否复制完整、有没有少字符

        · 测试结果会直接显示失败原因，照着改即可
