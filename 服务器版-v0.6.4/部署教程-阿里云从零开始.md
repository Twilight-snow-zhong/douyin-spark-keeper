# 从零部署完整教程：以阿里云轻量服务器为例

> ⚠️ **仅以此为例**：本文用阿里云做示范，具体服务器租赁平台可看个人选择（腾讯云 / 华为云 / 海外 VPS 流程大同小异）。

> 本教程面向**从没碰过服务器**的新手，手把手带你从注册账号一路跑到网页打开。
> 以国内最常见的**阿里云轻量应用服务器**为例（腾讯云轻量流程几乎一样，差异处有备注）。
> 全程大约需要 30~60 分钟（其中大部分时间是等服务器装环境）。

---

## 准备工作：你需要准备什么

- 一部手机（收验证码、实名认证、后续接收通知）
- 身份证（实名认证用）
- 支付宝或微信（付款）
- 一台你自己的电脑（Windows 就行，用于连接服务器、打开网页）

> 花费：轻量服务器有「新用户活动价」，2 核 2G 配置通常**几十到一百多元一年**，以购买页显示为准。
> 这是唯一的花费；服务器装好后的运行几乎不花钱。

---

## 第 1 步：注册阿里云账号

1. 浏览器打开阿里云官网：https://www.aliyun.com
2. 右上角点「免费注册」
3. 用手机号注册：填手机号 → 收验证码 → 设密码 → 完成
4. 注册后按提示完成**实名认证**（个人实名：身份证号 + 支付宝扫脸或上传证件照片，几分钟通过）

> 实名认证是买服务器的硬性要求，不认证买不了。

---

## 第 2 步：购买轻量应用服务器

1. 搜索「轻量应用服务器」或直接打开：
   https://www.aliyun.com/product/swas
2. 点「立即购买」，按下面选：
   - **地域**：选离你近的（如 广州 / 上海 / 深圳；有特殊需求可选香港/新加坡）
   - **镜像**：选 **系统镜像 → Ubuntu 22.04**（重要：不要选 Windows，我们的程序是 Linux 的）
   - **套餐**：2 核 2G 起步够用（1 核 1G 也行但会慢）；流量/带宽按需选最低档
   - **时长**：1 年（活动价最划算）
3. 确认订单 → 支付

> 腾讯云轻量版：https://cloud.tencent.com/product/lighthouse ，流程一样，镜像同样选 Ubuntu。

---

## 第 3 步：拿到服务器信息

1. 付款后进入控制台（阿里云控制台 → 轻量应用服务器 → 服务器列表）
2. 等 1~2 分钟，实例状态变「运行中」
3. 记下两样东西：
   - **公网 IP**（形如 `47.98.xx.xx`）
   - **登录密码**：控制台 → 实例详情 →「重置密码」（自己设一个，务必记住！）
   - 重置密码后控制台通常会提示重启实例，点确认

---

## 第 4 步：开放防火墙端口（关键！）

新服务器默认只开了 SSH（22 端口），我们的网页在 8000 端口，**不开放就访问不了**：

1. 控制台 → 该实例 →「防火墙」页签
2. 点「添加规则」：
   - 应用类型：自定义
   - 协议：TCP
   - 端口：`8000`（或填 `8000/8000`）
   - 来源：`0.0.0.0/0`（允许所有人访问；介意的话之后配 HTTPS 再收紧）
3. 保存

> 这样 22（SSH）和 8000（网页）两个端口就都通了。

---

## 第 5 步：连接服务器（Windows 电脑）

**方式 A：用 Windows 自带的终端（最简单，不需要装软件）**

1. 按 `Win + R`，输入 `powershell`，回车打开终端
2. 输入下面命令（把 IP 换成你的）：
   ```
   ssh root@你的公网IP
   ```
3. 第一次连接会问指纹确认，输入 `yes` 回车
4. 提示输入密码时，粘贴你在第 3 步设的密码（**输入时不显示任何字符，正常现象**），回车
5. 看到类似 `root@xxx:~#` 的提示符，就说明连上了

> 连不上？检查：① 密码对不对 ② 是否重启过实例 ③ 防火墙 22 端口是否开着。

**方式 B：图形化工具（想点鼠标的话）**

下载 **FinalShell**（www.hostbuf.com）或 **Xshell**（家庭版免费）：
新建连接 → 主机填 IP → 用户名 `root` → 密码 → 连接。

---

## 第 6 步：把程序上传到服务器

1. 在你自己电脑上找到 `服务器版` 文件夹（就是本文件夹）
2. 下载 **WinSCP**（https://winscp.net ，选简体中文版）并安装
3. 打开 WinSCP：
   - 主机名：你的公网 IP
   - 用户名：`root`
   - 密码：你的服务器密码
   - 点「登录」
4. 左侧是你电脑，右侧是服务器。右侧先进入 `/root` 目录
5. 把整个 `服务器版` 文件夹（含 `app.py`、`core`、`static`、`deploy` 等）**拖到右侧 /root 下**
6. 传完后关掉 WinSCP

> 上传几 MB 的代码文件很快。上传前可以把 `服务器版` 里的 `.env` 删掉（服务器上会自动生成新令牌，更安全）。

---

## 第 7 步：一键部署（等它跑）

回到刚才的 SSH 终端（或重新连上），执行：

```
cd /root/服务器版
sudo bash deploy/deploy.sh
```

脚本会自动做这些事（看到大量输出是正常的）：

- 安装 Python、虚拟环境、项目依赖
- **下载安装 Chromium 浏览器（几百 MB，这里最慢，5~15 分钟，耐心等）**
- 1G 内存机器自动创建 2G 交换空间
- 设置时区、生成访问令牌
- 注册 systemd 服务（开机自启 + 崩溃自动重启）

**看到这个就是成功了：**

```
======================================================
部署完成！
网页地址: http://你的IP:8000
访问令牌: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
======================================================
```

**把「访问令牌」记下来**（或者之后在服务器上执行 `cat /root/服务器版/.env` 查看）。

---

## 第 8 步：打开网页，开始使用

1. 在你自己的电脑浏览器打开：`http://你的公网IP:8000`
2. 输入访问令牌（第一次打开会要求输入）
3. 进入后：
   - 「账号管理」→ 添加账号
   - 「概览」→「📱 网页内扫码登录」→ 选引擎 → 点「开始扫码登录」
     - **用「网页内二维码」模式**（服务器没有桌面，弹窗模式已被自动禁用）
     - 用手机抖音 App 右上角「扫一扫」扫码确认
   - 「好友与消息」→ 获取聊天列表 → 勾选好友 → 填消息模板 → 保存
   - 「定时与浏览器」→ 设每天发送时间 → 开启「参与每日定时发送」
4. 先点「干跑测试」验证流程没问题，再点「立即发送」正式跑

---

## 第 9 步：配好手机通知（强烈建议）

服务器没有桌面，通知弹不出来。配 webhook 推到手机：

1. 网页左侧「🔔 通知」→ 开启「📱 webhook 推送」
2. 服务选 **ntfy**（最简单，免注册），地址填：`https://ntfy.sh/随便起个话题名`
3. 手机安装 **ntfy** App，订阅同一个话题名（或用手机浏览器直接打开该地址）
4. 点「🧪 发送测试通知」→ 手机收到即成功

## 日常管理速查

| 想做什么 | 操作（SSH 连接服务器后） |
|---|---|
| 看程序状态 | `systemctl status douyin-spark` |
| 重启程序 | `sudo systemctl restart douyin-spark` |
| 看实时日志 | `journalctl -u douyin-spark -f`（Ctrl+C 退出） |
| 停止程序 | `sudo systemctl stop douyin-spark` |
| 修改端口/令牌 | 编辑 `nano /root/服务器版/.env` → 保存 → `sudo systemctl restart douyin-spark` |
| 备份数据 | 网页「账号管理」→「⬇️ 备份全部数据」下载 zip |

---

## 常见卡壳点

- **网页打不开？** → 检查第 4 步防火墙 8000 端口是否添加；确认 `systemctl status douyin-spark` 是 active
- **SSH 连不上？** → 密码错 / 没重启实例 / 22 端口被防火墙挡
- **部署脚本报错？** → 把报错最后几行截图；多数是网络问题，重跑一次 `sudo bash deploy/deploy.sh` 即可（脚本可重复执行）
- **扫码登录失败？** → 确认用的是「网页内二维码」模式；`journalctl -u douyin-spark -f` 看日志
- **服务器被攻击？** → 公网部署务必尽快配 HTTPS；令牌别外泄；不需要时可到阿里云控制台关闭 8000 端口规则

## 备用：不用阿里云，还有这些选择

| 平台 | 特点 | 备注 |
|---|---|---|
| 腾讯云轻量 | 流程和本教程几乎一样 | 默认用户是 `ubuntu` 而非 `root`，连接后先 `sudo -i` 再操作 |
