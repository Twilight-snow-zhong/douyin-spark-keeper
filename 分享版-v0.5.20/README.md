# 抖音续火花助手（Douyin Spark Keeper）v0.5.20

一个**自托管**的抖音"续火花"自动化工具：每天定时自动给指定好友发送一条私信，维持聊天火花（🔥）不熄灭。

**本文件夹即 v0.5.20 个人版**程序本体。基于 **Python + FastAPI + Playwright**，Windows 本机双击即可运行。

> ⚠️ 本版本为早期版本，最新个人版见 `分享版-v0.5.25`，服务器部署版见 `服务器版-v0.5.26`（仓库根 README 有对比表）。
> 自动化发私信违反抖音社区公约，存在被风控、限流甚至封号的风险，仅限本人账号、少量好友、每天一条的个人自用场景，使用后果自负。

## 功能特性

**多账号**
- 多账号管理：增删改查、账号级启用开关，每个账号独立的登录态 / 好友 / 定时 / 日志 / 历史
- 不同账号可用不同浏览器引擎（Chromium / Firefox / WebKit），Cookie 完全隔离
- 多账号**串行执行**（一次只跑一个），避免同 IP 并发触发风控

**扫码登录（多浏览器）**
- 网页内扫码登录：选浏览器 → 点「开始扫码登录」→ 桌面弹出真实浏览器窗口（或网页内二维码）→ 手机扫码自动关联账号
- 自动检测本机浏览器（Edge / Chrome / 夸克 / 360 / QQ），支持自定义浏览器路径
- 登录方式可切换：弹出浏览器窗口（推荐）/ 网页内二维码

**发送核心**
- 好友一键勾选：从聊天列表自动读取好友（含火花天数），勾选即用
- 每日定时发送：**抖动窗口可设 0 = 准点发送**；设为 N 则在设定时间后 0~N 分钟内随机
- 历史记录显示实际发送延迟（"晚 X 秒"）
- 防错发保护：切换校验 + 搜索兜底 + 发送后校验；失败自动重试、当日自动补发一次
- 限流检测：识别"操作频繁 / 安全验证"提示，命中立即停止本轮

**管理与提醒**
- 开机自启动：网页一键开关，可选最小化运行 / 正常窗口
- Windows 桌面通知：发送完成 / 登录过期 / 疑似限流时右下角弹系统气泡
- 历史记录页 + 账号级/全局日志；网页端修改访问令牌

## 快速开始（Windows 本机）

1. 双击 **`start.bat`**（首次自动安装依赖与 Chromium），约 3 秒后浏览器自动打开管理页面
2. 打开 `http://127.0.0.1:8000`，输入访问令牌（首次启动自动生成，见 `.env` 的 `AUTH_TOKEN`）
3. 「概览」→「📱 网页内扫码登录」→ 选浏览器 →「开始扫码登录」→ 手机抖音扫码关联账号
4. 「好友与消息」→ 获取聊天列表 → 勾选好友 → 填消息模板 → 保存
5. 「定时与浏览器」→ 设发送时间、抖动窗口（测试建议 0）→ 保存
6. 「概览」→ 先「干跑测试」→ 再「🚀 立即发送」

> 手动安装：`python -m pip install -r requirements.txt` + `python -m playwright install chromium`

## 抖动窗口

| 设置 | 行为 |
|------|------|
| **0** | 到点准点立即发送（推荐测试用） |
| **N 分钟** | 到点后在 0 ~ N 分钟之间随机一个时刻发送（模拟真人节奏） |

## 安全与合规

- 访问令牌随机生成，保存在 `.env`，本机默认只监听 `127.0.0.1`
- `state.json` 与 `.env` 属敏感数据，切勿提交到仓库或分享（`.gitignore` 已排除）
- 自动化发私信违反抖音社区公约，仅限个人低频自用，风险自负
