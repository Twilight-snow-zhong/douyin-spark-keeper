📖 使用说明

没看过 README 也没关系，这里 3 分钟带你上手：添加账号 → 关联抖音 → 加好友 → 设定时，之后每天自动帮你续火花。

🚀 快速上手（3 步）
1添加账号

「账号管理」→「+ 添加账号」，给账号起个名字（如大号 / 小号），支持多账号同时管理。

2关联抖音

「概览」→「📱 网页内扫码登录」，用手机抖音 App 右上角扫一扫确认登录。也可以用 extract_cookie.py 导出登录态后上传。

3加好友 + 设定时

「好友与消息」：获取聊天列表 → 勾选好友加入名单 → 填好消息模板 → 保存。「定时与浏览器」：设好每天发送时间，开启「参与每日定时发送」。

🗺 各页面说明

📊 概览

  • 当前账号的登录态、会话状态、下次发送倒计时
  • 卡片墙：点任意卡片切换当前账号（当前账号置顶）
  • 🚀 立即发送 / 干跑测试（不真发）/ 只发指定好友
  • 📱 网页内扫码登录、上传登录态（state.json）
  • 开机自启动开关（最小化 / 正常窗口）

👥 好友与消息

  • 「获取聊天列表」读取抖音聊天对象（带火花天数🔥）
  • 勾选后加入好友名单，每个好友可单独启用 / 停用
  • 消息模板：每行一条，每次发送随机选一条
  • 只给「启用」的好友发送，改完记得点保存

⏰ 定时与浏览器

  • 每天发送时间 + 时间抖动（设定时间后 0~N 分钟随机）
  • 好友发送间隔、每次最多人数（0=不限）、失败自动补发
  • 浏览器引擎：多账号选不同引擎可降低账号间关联
  • 无头模式：关闭后弹出浏览器窗口便于观察

📜 历史记录

  • 每次运行的成功 / 失败名单、发送延迟、异常标记
  • 可筛选：全部 / 干跑测试 / 真实发送 / 有异常
  • 失败的好友悬停可看失败原因

📄 日志

  • 账号日志 / 全局日志切换，支持自动刷新
  • 📋 一键复制日志，排查问题时方便反馈

🗂 账号管理

  • 添加 / 重命名 / 删除账号，↑↓ 调整显示顺序（同步到侧边栏和概览卡片墙）
  • ⚡ 全部账号立即发送：所有启用账号串行跑一轮
  • ⬇️ 备份全部数据：打包下载登录态 / 好友名单 / 历史
🔧 侧边栏底部工具

❓ 常见问题

概览会显示红色提示。点「📱 网页内扫码登录」重新扫码关联；或在本机命令行运行 python extract_cookie.py 重新导出后，在概览「选择 state.json」上传。

工具已自动停止本轮，稍后会自动补发。建议把时间抖动调大一点、每次发送人数调低，别发太频繁；若频繁限流请暂停使用一段时间。

浏览器引擎没安装。在任意命令行窗口运行 python -m playwright install firefox webkit（首次需下载，约几分钟），装完在扫码对话框点「🔄 重新检测浏览器」。

先检查 Windows「设置 → 系统 → 通知」总开关是否打开、「专注助手（勿扰）」是否开启。然后在「🔔 通知」设置里点「🧪 发送测试通知」验证。

依次检查：账号是否「启用」、好友名单里是否有「启用」状态的好友、登录态是否有效（概览会话状态）、时间是否设对。还不行就看「日志」页排查。

旧机器「账号管理」点「⬇️ 备份全部数据」下载 zip；新机器装好后点「♻️ 恢复备份」选择该 zip，即可一键还原所有账号的登录态、好友名单、配置与历史。
