# 抖音续火花助手（Douyin Spark Keeper）

一个**自托管**的抖音"续火花"自动化工具：每天定时自动给指定好友发送一条私信，维持聊天火花（🔥）不熄灭。

**支持多账号管理**：每个账号独立登录态、独立好友名单、独立定时与日志，可为不同账号选用不同浏览器引擎。提供网页管理界面，日常**完全无人值守**——只需在登录态过期时重新扫码一次。基于 **Python + FastAPI + Playwright** 实现，Windows 本机双击即可运行，也支持 Debian/Ubuntu 一键部署。

> ⚠️ 仅限本人账号、少量好友、每天一条的**个人自用**场景。自动化发私信违反抖音社区公约，存在被风控、限流甚至封号的风险，使用后果自负。请勿用于批量营销、多账号运营或对外提供服务。

## 功能特性

**界面与体验（v0.6.0）**
- 管理后台式布局：左侧导航 + 内容区，**深浅色主题**（跟随系统，可手动切换）
- 概览账号卡片墙：每行 2 个、多账号可左右滑动，含会话状态 / 浏览器 / 下次发送**倒计时**
- 账号管理：**上移/下移排序**（同步侧边栏与卡片墙）、⚡ **全部账号立即发送 / 干跑测试**
- **一键备份 / 恢复**：打包下载全部账号数据，换机一键还原
- 好友**搜索过滤**、历史记录**筛选**、日志一键复制、网页内「📖 使用说明」页
- 点左侧导航**自动刷新**对应页面数据；日志区跟随深浅色主题、打开自动滚到最新；头像抓取失败等报错自动折叠，点开看详情
- 「好友与消息」「定时与浏览器」重设计：卡片式分区、实时预览、等宽对齐的表单标签

**多账号**
- 多账号管理：增删改查、账号级启用开关，每个账号独立的登录态 / 好友 / 定时 / 日志 / 历史
- 不同账号可用不同浏览器引擎（Chromium / Firefox / WebKit），Cookie 完全隔离
- 多账号**串行执行**（一次只跑一个），避免同 IP 并发触发风控
- 旧版单账号数据自动迁移为默认账号，无需手动搬文件

**扫码登录（多浏览器）**
- **网页内扫码登录**：弹窗里选浏览器 → 点「开始扫码登录」→ 桌面弹出真实浏览器窗口（或网页内二维码）→ 手机扫码即自动关联账号，并用主页昵称自动重命名
- **自动检测本机浏览器**：Microsoft Edge / Chrome / 夸克 / 360 / QQ 等，装好的自动出现在列表；也支持**自定义浏览器路径**
- 登录方式可切换：**弹出浏览器窗口**（最稳，推荐）/ **网页内二维码**

**发送核心**
- 好友一键勾选：从聊天列表自动读取好友（**含头像 + 火花天数** + 上次聊天时间），勾选即用，支持全选 / 取消全选，抓取时有实时进度提示，自动保存
- **🔄 同步火花**：手动或每次发送后自动刷新好友名单的火花天数（天数变小自动判定「重燃」）；右上角有全局同步进度横幅
- 好友名字锁定不可改（发送靠名字匹配），备注可自由填写
- 每日定时发送：**抖动窗口可设 0 = 准点发送**；设为 N 则在设定时间后 0~N 分钟内随机（模拟真人节奏）
- **历史记录显示实际发送延迟**：每次定时任务"晚 X 秒"一目了然，可验证抖动效果
- 防错发保护：点击后校验右侧会话标题；搜索兜底；发送后校验输入框已清空
- 真实发送校验：失败自动重试一次；当日自动补发一次（等待时长可配）
- 限流检测：识别"操作频繁 / 安全验证"提示，命中立即停止本轮
- **只发指定好友**：临时给某几个人补发，不动正式名单，可干跑

**管理与提醒**
- **开机自启动**：网页一键开关，可选**最小化运行 / 正常窗口**
- **Windows 桌面通知**：发送完成 / 登录过期 / 疑似限流时右下角弹系统气泡，零注册零配置；「发送测试通知」带系统状态检测
- 历史记录页：最近 30 次执行明细，可展开查看成功/失败名单
- 账号级日志 + 全局日志，网页内切换查看；网页端修改访问令牌

## 快速开始（Windows 本机）

> 本文件夹即 **v0.6.0 个人版**程序本体，双击 `start.bat` 即可运行。
> 更多版本（旧版 / 服务器版）见仓库根 README 的版本对比表。

### 1. 启动服务

双击本文件夹的 **`start.bat`**（全新电脑会**自动安装 Python / 依赖 / Chromium**，全程只需联网，首次约几分钟），约 3 秒后浏览器自动打开管理页面。

> Python 检测顺序：`python-path.txt` 自定义路径 → PATH 里的 python（逐个验证，跳过商店假别名）→ py 启动器 → 常见安装目录 → 本文件夹便携版 → 自动安装。
> 如果你的 Python 在很特殊的位置且没加进 PATH：在 start.bat 同目录建一个 `python-path.txt`，第一行写上 python.exe 的完整路径即可。

> 若手动安装：`python -m pip install -r requirements.txt` + `python -m playwright install chromium`

### 2. 关联抖音账号

打开 `http://127.0.0.1:8000`，输入访问令牌（首次启动自动生成，见本文件夹 `.env` 的 `AUTH_TOKEN`，浏览器会记住）。

在「概览」页点 **📱 网页内扫码登录**：
1. 弹窗中选择浏览器（默认 Chromium，也可选检测到的 Edge/Chrome 等）
2. 点 **「▶ 开始扫码登录」**
3. 桌面弹出真实浏览器窗口 → 用手机抖音 App 扫码 → 自动关联当前账号

> 备用方式：命令行运行 `python extract_cookie.py` 导出登录态文件，再到网页「概览」点「选择 state.json」→「上传登录态」。

### 3. 配置好友与定时

1. 「好友与消息」→「获取聊天列表」→ 勾选好友（自动保存）→ 保存
2. 「定时与浏览器」→ 设发送时间、抖动窗口（测试时建议 **0** = 准点）→ 保存
3. 「概览」→ 先点「干跑测试」验证，再点「🚀 立即发送」

之后每天自动运行。唯一人工介入时机：网页顶部标红提示"登录态已过期"时，重新扫码关联。

### 4. 开启开机自启动（可选）

「概览」页打开「开机自启动」开关 → 选择 **最小化运行 / 正常窗口** → 下次登录 Windows 自动运行（最小化运行会以最小化黑窗口出现在任务栏）。

### 5. 多账号

「账号管理」→「+ 添加账号」→ 切到新账号 → 扫码关联 → 配置好友与时间。建议不同账号用不同浏览器、不同发送时间，降低关联。

## 抖动窗口（重要）

| 设置 | 行为 |
|------|------|
| **0** | 到点**准点立即发送**（推荐测试用） |
| **N 分钟** | 到点后在 **0 ~ N 分钟之间随机**一个时刻发送（每天不同，模拟真人） |

历史记录页的「发送延迟」列会显示每次实际晚了几秒，方便你验证。

## 通知设置

「通知设置」→「桌面通知」开关（默认开启）：
- 发送完成、登录过期、疑似限流时，电脑**右下角弹系统通知气泡**
- 点「🧪 发送测试通知」验证；若系统屏蔽通知（如**专注助手**开着或**系统通知总开关**关闭），测试结果会直接提示你去哪里打开

## 浏览器引擎与"换指纹"

「定时与浏览器」页可为每个账号选引擎：
- **Chromium**（最稳定，推荐）
- **Firefox / WebKit**：不同引擎 = 不同浏览器指纹（UA/渲染等），给不同账号用不同引擎可降低账号关联，即"换指纹用"。使用前需安装：`python -m playwright install firefox webkit`
- 页面会显示各引擎**安装状态**（✅/❌）

## 自动发送策略与保护机制

- **切换校验**：点击联系人后，必须确认右侧会话顶部标题出现目标昵称，才继续发送，杜绝"发给上一个人"。
- **搜索兜底**：列表点不到（懒加载/名字不在最近聊天）时，自动用搜索框查找并点「发消息」直接打开会话。
- **发送校验**：文字进入输入框 → 按 Enter → 文字离开输入框，三步都满足才算成功；失败自动重试一次。
- **当日补发**：本轮存在失败好友时，按账号配置的等待时间（默认 45 分钟）只对失败者补发一次。
- **限流熔断**：检测到"操作频繁 / 安全验证"等提示立即停止本轮。
- **节奏拟人化**：抖动窗口 + 好友随机间隔 + 随机文案，模拟真人节奏。
- **多账号串行**：全局同一时刻只运行一个任务。

## 常见问题

- **状态显示"登录态已过期"**：重新「网页内扫码登录」即可。
- **定时发送没到点**：检查抖动窗口——设了 N 分钟会在 0~N 分钟内随机发送；设 0 即准点。
- **桌面通知没气泡**：检查 Windows 系统通知总开关（设置 → 系统 → 通知）与专注助手；测试按钮会提示具体原因。
- **Firefox/WebKit 不可用**：运行 `python -m playwright install firefox webkit`；页面会显示安装状态。
- **扫码登录没反应**：确认已点「▶ 开始扫码登录」按钮（弹窗默认不再自动启动）。
- **提示操作频繁**：调大"好友间隔"、减少每次发送人数；少量好友（几个到十几个）最稳。
- **Chromium 下载慢/失败**：可设置镜像 `PLAYWRIGHT_DOWNLOAD_HOST`（如 `https://npmmirror.com/mirrors/playwright`）。
- **头像显示占位图标**：抖音头像链接有时效，重新「获取聊天列表」或「🔄 同步火花」即可刷新。

## 安全与合规

- 访问令牌随机生成，保存在 `.env`，可在网页端修改；本机默认只监听 `127.0.0.1`。
- `state.json` 与 `.env` 属敏感数据，**切勿提交到仓库或分享**（`.gitignore` 已排除）。
- 本项目违反抖音社区公约中"未经平台允许采用自动化手段发私信"的规定，账号可能被限流或封禁。仅限个人低频自用，请自行承担风险。
