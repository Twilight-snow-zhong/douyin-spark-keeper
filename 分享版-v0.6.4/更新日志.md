## v0.6.3（模板行编辑器 + 日志折叠 · 个人开发版快照 · 未打包）

### v0.6.3 新增 / 调整
- **💬 消息模板 → 逐行编辑器（方案①）**：模板区从大文本框改为**每行一个输入格**
  - 行首 `【火花】/【贴纸:名】/【图:文件名】` 自动显示为**前置小图标**，输入格只编辑剩余文字；行内其余标记仍以文字保存（行尾有图标提示）
  - 底部「＋ 添加一行」「📋 多行粘贴」（弹窗整段粘贴自动拆行）；空行显示精简占位提示，有内容（文字或图标）即消失
  - 数据源重构为**单源行数组**（tplRows）：打字只改当前行、光标稳定不跳、不整块重渲染（修复了此前多次"整个卡片消失"的根因——未 return 的模板变量 templateLines，现已补 return）
  - 对比过的 方案②富文本（contenteditable）与样式切换 UI 未采用，已移除
- **📄 日志折叠（体验优化）**
  - 日志先按**时间戳归组**：无时间戳的续行/堆栈（Call log、locator 等）并入上一条，算作同一条日志
  - 只要**整条会超过一行**（多行续行或单行放不下）即折叠：按**实际字宽**截断，截断+「展开全文」**硬性一行**（flex+nowrap+省略号兜底，绝不折行）
  - 展开=**同一段文字无缝续接**完整原文（保留换行），文末「收起」按钮收回；展开态下方不再有多余空行
  - 窗口宽度变化 / 打开日志页时自动重新测量自适应
- **稳定性修复**：修复 setup 中 state 声明被误删（dirty/emojis/doPasteTpl/addLineMarker）导致的运行时 ReferenceError（已恢复并全量 0 报错）
