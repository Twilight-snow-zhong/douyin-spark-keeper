# 抖音续火花助手（分享版）

多账号**抖音自动续火花**工具：每天定时给好友发消息，维持聊天火花不断。
支持多账号管理、网页扫码登录、定时发送（带随机抖动防限流）、失败自动补发、桌面通知 / webhook 手机推送、数据备份恢复。

## 快速开始（Windows 个人版）

1. 下载 `分享版-v0.6.4/` 整个文件夹
2. 双击 `start.bat`（或命令行 `python app.py`）
3. 浏览器打开 `http://127.0.0.1:8000`，输入访问令牌（首次运行自动生成，保存在 `.env`）
4. 「账号管理」添加账号 → 「概览」网页内扫码登录 → 「好友与消息」配置名单和消息模板 → 「定时与浏览器」设好发送时间并开启参与定时

## 服务器部署

见 `服务器版-v0.6.4/DEPLOY_SERVER.md` 与《部署教程-阿里云从零开始.md》：
上传文件夹 → `sudo bash deploy/deploy.sh` 一键部署 → 网页配置账号与定时 → 配 webhook 推送到手机。

## 常见问题

- 登录态过期 → 重新「网页内扫码登录」，或用 `extract_cookie.py` 重新导出后上传
- 疑似限流 → 已自动停止并稍后补发，建议调大时间抖动、调低每次发送人数
- 详细使用说明 → 打开网页后左侧「📖 使用说明」
